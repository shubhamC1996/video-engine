VIDEO ENGINE — MOBILE STARTER

इस ZIP में अभी एक शुरुआती PWA मोबाइल इंटरफेस है:
- Text to Video / Photo to Video मोड
- फोटो चुनना और preview
- Shorts/Reels ratio और duration चयन
- Prompt तैयार करना
- PWA manifest और basic offline cache

महत्वपूर्ण:
यह अभी AI वीडियो जनरेट नहीं करता। वास्तविक rendering के लिए compatible video-generation model/API या आपके अपने server पर चलने वाला model जोड़ना होगा। बिना paid API के विकल्प मॉडल और उपलब्ध free hosting पर निर्भर होंगे; unlimited free generation की गारंटी नहीं है।

मोबाइल पर इस्तेमाल:
1. ZIP को extract करें।
2. इन फाइलों को किसी static hosting पर publish करें (उदाहरण: GitHub Pages या Netlify की free tier; उनकी मौजूदा limits लागू होंगी)।
3. HTTPS URL को Chrome में खोलें।
4. Chrome मेनू > Add to Home screen चुनें।

सिर्फ local file खोलने से PWA install/offline सुविधाएँ हर browser में काम नहीं करेंगी।
